# 天气地图 🌤

上海周边 18 城市未来 7 天天气预报，以地图形式直观展示。支持全球地图漫游。

## 数据源

- 🗺 地图：Leaflet.js + CartoDB Dark（免费）
- 🌤 天气：Open-Meteo API（免费，无需 Key）
- 🌐 覆盖 18 个城市：上海、苏州、杭州、南京、宁波、无锡、嘉兴、南通、绍兴、常州、合肥、舟山、湖州、台州、镇江、扬州、芜湖、马鞍山

## 启动方式

最简单：**双击文件夹里的 `打开天气地图.webloc` 快捷方式**。

如果手动在浏览器输入，请**完整精确输入**：

```
http://127.0.0.1:8004
```

⚠️ 注意事项：
- ✅ 用 `127.0.0.1`（**不要**用 `localhost` 或 `www.localhost.com`，浏览器会把它当成外网域名）
- ✅ 前面必须加 `http://`
- ✅ 端口是 `8004`

命令行启动：

```bash
cd /Users/lijiahang/长三角天气地图
python3 app.py
```

## 功能

- 地图上每个城市显示当天天气图标 + 最高/最低温
- 点击城市弹出 7 天逐日预报（含天气描述、降水量）
- 深色主题，响应式设计
- 每小时自动刷新
- 请求失败时显示错误提示条，可一键重试
